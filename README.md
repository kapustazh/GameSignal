# GameSignal

A concept landing page for a platform helping game developers find existing tools, understand player feedback, and prepare for release.

## Preview locally

Run `python3 -m http.server 4173 --directory public`, then open http://localhost:4173.

## Deploy

Import this repository into Vercel. `vercel.json` publishes only `public/`; no install or build command is required.

The workflow examples are illustrative. There is no AI backend or account integration in this concept page. Project interest links to this repository.
